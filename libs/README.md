# Biblioteca PS2X_lib

Biblioteca usada para ler o controle de PS2 (sem fio, via receptor) no Arduino.

- Autor original: Bill Porter (versão 1.8 do cabeçalho), com contribuições de Eric Wetzel e Kurt Eckhardt.
- Licença: GNU GPL v3 ou posterior (texto no cabeçalho de `PS2X_lib/PS2X_lib.h`).
- Esta cópia é a mesma usada no Fórmula RPS, apenas sem o arquivo `.DS_Store`.

Como instalar na Arduino IDE: Sketch > Incluir Biblioteca > Adicionar biblioteca .ZIP e escolha o `PS2X_lib.zip` desta pasta.

A licença MIT da raiz do repositório vale para o código do Tio Rafa. A PS2X_lib mantém a licença dela.
